# BalancePaper

혼자 식단을 관리하기 어려운 사용자를 위한 건강 식단 기록 웹사이트입니다.

팀 프로젝트로 제작한 냉장고 재료 기반 레시피 서비스 `FridgePaper`를 분석한 뒤, 서비스 목적과 사용자 흐름을 새롭게 구성한 개인 리디자인 포트폴리오입니다.

## 리디자인 이유

기존 서비스는 레시피 추천, 장보기, 음식물 절약 등 여러 목적이 섞여 핵심 흐름이 분산되어 있었습니다. 이를 개선하기 위해 매일 반복할 수 있는 식사 기록에 집중했습니다.

> 목표 설정 → 식사 기록 → 영양 분석 → 다음 끼니 제안

## 주요 기능

- 감량, 유지, 증량 목표 설정
- 식사 사진 등록과 미리 보기
- 음식 섭취량에 따른 예상 칼로리 계산
- 칼로리, 탄수화물, 단백질 섭취 현황 표시
- 다음 끼니에서 실천할 수 있는 식단 조절 방법 제안
- 반응형 화면과 모바일 메뉴

## 폴더 구성

```text
balancepaper/
├── index.html
├── css/
├── js/
├── subpage1/   # 목표 설정
├── subpage2/   # 식단 기록
├── subpage3/   # 섭취 분석
├── subpage4/   # 균형 제안
├── mypage/
└── privacy/
```

## 구현 범위

웹 퍼블리싱과 UI·UX 설계를 보여주기 위한 정적 프로토타입입니다. 실제 AI 음식 분석, 영양 데이터베이스, 회원 서버는 연결되어 있지 않으며 화면의 정보는 포트폴리오용 예시 데이터입니다.
