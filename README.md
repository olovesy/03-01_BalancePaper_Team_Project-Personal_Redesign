# BalancePaper

팀 프로젝트 FridgePaper를 개인적으로 다시 분석하고, 건강 식단 기록 서비스로 리디자인한 포트폴리오입니다.

## 폴더 구성

- `index.html`: 메인 화면
- `subpage1/index.html`: 목표 설정
- `subpage2/index.html`: 식단 기록
- `subpage3/index.html`: 섭취 분석
- `subpage4/index.html`: 균형 제안
- `mypage/index.html`: 사용자 정보 화면
- `privacy/index.html`: 개인정보 이용 안내
- `css/var.css`: 공통 색상과 크기
- `css/reset.css`: 브라우저 기본 스타일 초기화
- `css/font.css`: 폰트 설정
- `css/health.css`: 전체 페이지 디자인과 반응형 스타일
- `css/mypage.css`: 마이페이지 전용 디자인
- `js/health.js`: 메뉴, 사진 미리 보기, 칼로리 계산, 버튼 선택
- `js/mypage.js`: 마이페이지 화면 동작

## 사용 기술

- HTML
- CSS
- JavaScript
- 반응형 웹

## 참고

사진 분석과 영양 정보는 포트폴리오 화면을 보여주기 위한 예시입니다. 실제 AI 분석이나 서버 통신은 사용하지 않습니다.
